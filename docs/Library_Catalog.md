## PREAMBLE

This Library Catalog is the **complete inventory** of the AVCS discipline.

It does not define AVCS. It does not interpret AVCS. It does not replace any governing document.

It **classifies** every artifact, **assigns** every artifact to a shelf, and **defines** the reading order for every audience.

Where this Catalog and any governing document appear to conflict, the **governing document prevails**.

---

## CLASSIFICATION CRITERION

**Criterion:** Authority Level + Function

Each artifact is classified by:

1. **What authority it carries** (level).
2. **What it does** (function).
3. **Who it is for** (audience).
