## PREAMBLE

This System Navigator is the **map of the AVCS discipline**.

It does not define AVCS. It does not interpret AVCS. It does not replace any governing document.

It **shows how the documents relate to one another**, **in what order they should be read**, and **which document governs in which domain**.

Where this Navigator and any governing document appear to conflict, the **governing document prevails**.
